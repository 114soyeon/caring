# 돌하루팡 리뉴얼 (TEAM 카링)

> **여행의 첫 단계, 렌트카 예약을 더 넓고 단순하게**
> 제주 렌트카 가격비교 서비스 돌하루팡의 화면 구조와 정보 위계를 다시 설계한 UX/UI 리뉴얼 프로젝트

링크

- 배포 사이트 : [돌하루팡 리뉴얼 바로가기](https://114soyeon.github.io/caring)
- GitHub : [저장소](https://github.com/114soyeon/caring)
- 원본 사이트 : [돌하루팡 렌트카](https://www.dolharupang.com/cars)

<br>

## 기획 의도

**불편한 점**

- 콘텐츠가 화면 가운데 절반 정도에만 몰려 있어, 큰 화면에서 정보가 작게 보인다.
- 헤더에 배너, SNS, 아이콘, 로고, 8개 메뉴가 겹쳐 있어 시선이 흩어진다.
- 검색, 예약 현황, 안내, 후기가 비슷한 무게로 나열되어 무엇부터 봐야 할지 모른다.
- 어떤 버튼을 눌러도 상단 이미지가 그대로라 페이지가 바뀐 느낌이 없다.

**해결 방법**

- 화면 폭을 넓게 쓰고, 목록은 카드형 그리드로 한눈에 비교할 수 있게 한다.
- 헤더는 로고와 핵심 메뉴 4개(렌트카, 최저가 숙소, 혜택 및 이벤트, 이용가이드)로 줄인다.
- 페이지마다 다른 제주 사진과 제목을 두어 지금 어디에 있는지 알 수 있게 한다.
- 장소·날짜는 한 줄 검색바에서 바로 고르고, 이용 고객 수·실시간 예약·제주 날씨는 한 영역에 모은다.

## 주요 화면 & 기능

### 1. 메인

<img src="docs/main.png" alt="메인 화면" width="100%" />

> 나혜진 : 메인 페이지 디자인, 퍼블리싱

## 트러블 슈팅

### 권지원 (alice207116116-debug)

**어려웠던 점**

- 차량 카드의 화살표를 눌러 상세를 펼치면, 같은 줄에 있는 옆 카드까지 함께 길어져서 둘 다 열린 것처럼 보였다.

**해결 방법**

- 그리드는 기본으로 같은 줄의 칸을 가장 긴 칸 높이에 맞춰 늘린다. 정렬을 위쪽 기준(`align-items: start`)으로 바꿔 카드가 각자 자기 높이만큼만 차지하게 했다.

**배운 점**

- 화면이 이상하게 움직일 때 원인이 기능이 아니라 레이아웃의 기본값일 수 있다는 걸 알게 됐다.

### 김미래 (mimimiqqq)

**어려웠던 점**

- 숙소 사진의 모서리가 둥글지 않고 각져 보였다.

**해결 방법**

- `border-radius: var(--radius)`로 지정했는데, `--radius` 변수가 어디에도 정의되어 있지 않았다. 변수에 기대지 않고 24px로 직접 지정했다.

**배운 점**

- 정의되지 않은 변수는 오류 없이 무시돼서 원인을 찾기 어렵다. 변수를 쓸 때는 실제로 정의되어 있는지 먼저 확인해야 한다.

### 김소연 (114soyeon)

**어려웠던 점**

- 헤더와 푸터를 공통으로 작업했는데, 다른 팀원의 페이지에서 깨져 보였다. 공통 작업을 올리는 과정에서 다른 페이지 작업물까지 함께 커밋되어 파일이 꼬인 상태였다.

**해결 방법**

- 각자 담당한 페이지에는 작업한 헤더와 푸터가 살아 있는 것을 확인했다. 메인에 있는 작업물을 브랜치로 받고 다시 올리는 과정을 반복해 모든 페이지의 헤더와 푸터를 바로잡았다.

**배운 점**

- 여러 사람이 같이 쓰는 부분은 작은 실수도 모든 페이지에 퍼진다. 올리기 전에 내 작업만 들어갔는지 확인해야 한다.

### 나혜진 (nahj272)

**어려웠던 점**

- 미리 맞춰 둔 슬라이더 크기와 원본 이미지 비율이 맞지 않아 이미지가 잘리거나 어색하게 보였다.

**해결 방법**

- 슬라이더 크기를 원본 이미지 비율(2200 × 1000)에 맞게 1100 × 500으로 줄이고, 화면이 줄어도 같은 비율을 유지하게 했다.

**어려웠던 점**

- 메인의 제주 날씨가 항상 같은 요일 순서로 고정되어 있어, 언제 접속해도 요일과 기온이 실제 날짜와 맞지 않았다.

**해결 방법**

- 오늘 날짜를 기준으로 7일치 요일을 계산해 그리도록 바꿨다. 무료 날씨 API(Open-Meteo)로 제주 예보를 받아 최고·최저 기온을 채우고, 받아오지 못하면 기본값을 보여주게 했다.

**배운 점**

- 이미지는 크기보다 비율을 먼저 맞춰야 어떤 화면에서도 깨지지 않는다.
- 날짜처럼 바뀌는 정보는 직접 적지 말고 계산하거나 받아와야 한다.
